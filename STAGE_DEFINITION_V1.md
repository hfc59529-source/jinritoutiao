# Stage Definition V2

## Stage 1: Collect

Purpose:
Bring valid source material into the Today Toutiao system.

Responsibility:
Obtain complete and authentic high-performing source articles from the teacher website.

Boundary:
This stage defines what can enter the system. It does not define how source material is collected.

## Stage 2: Transform

Purpose:
Create Today Toutiao-ready content from collected source material.

Responsibility:
Convert source material into content that fits Today Toutiao publishing needs.

Boundary:
This stage defines what transformation means. It does not define how transformation is performed.

## Stage 3: Review

Purpose:
Confirm whether the Toutiao article preserves the source article's distribution potential and meets Today Toutiao publishing standards.

Responsibility:
Check, judge, and output a Review Decision.

Boundary:
This stage defines Review as a decision point. It does not modify, regenerate, or publish the article.

## Stage 4: Revision

Purpose:
Revise content only when Review Decision is REVISION.

Responsibility:
Modify content according to the Review Decision and return it to Review.

Boundary:
This stage is a rework branch. It is not part of the PASS path.

## Stage 5: Publish

Purpose:
Release approved content to Today Toutiao.

Responsibility:
Publish approved content on Today Toutiao.

Boundary:
This stage defines publishing. It does not define publishing time, frequency, or schedule.

## Stage 6: Feedback

Purpose:
Make post-publish performance visible to the system.

Responsibility:
Collect performance data after publishing to support future improvement.

Boundary:
This stage defines feedback. It does not define analysis methods.
