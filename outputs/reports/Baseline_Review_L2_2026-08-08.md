# Baseline Review L2｜差异层 (2026-08-08)

数据源：`data/baseline_review/baseline_articles_2026-08-08.csv`（同 L1，46条已发布文章）
前置：L1 已冻结（见 `Baseline_Review_L1_2026-08-08.md`）

本报告只回答"46条文章在展现、阅读转换、收益三个阶段分别存在什么**可观察差异**"，不回答"为什么"。所有对比均为 Observed Difference（观察到的差异），不构成 Causal Explanation（因果解释）。未使用任何内容标签（标题结构/主题类型/情绪强度等），只使用 Baseline Dataset 已有结构化字段：`word_count`（字数）、标题长度（由 title 字段派生）、`publish_time_cn`（发布时间→小时/星期）、`impressions`、`reads`、`reading_rate = reads/impressions`、`click_rate`（平台字段，与 reading_rate 口径一致）、`read_complete_rate`、`read_duration`、`comments`、`favorites`、`revenue`。

## 0. 三组代表案例对照表

| 案例 | 展现 | 阅读 | 阅读率 | 收益 | 字数 | 标题长度 | 发布时间 |
|---|---|---|---|---|---|---|---|
| A｜赣锋锂业 | 4,270 | 269 | 6.3% | ¥0.09 | 2,003 | 25字 | 2026-07-21 21:11（周二） |
| B｜酒店早餐券灰产 | 8,932 | 2 | 0.02% | ¥0.01 | 1,074 | 31字 | 2026-07-22 15:00（周三） |
| C｜亚马逊自动续费 | 1,892 | 74 | 3.9% | ¥0 | — | — | — |

三案例共同点：均进入 46 篇的**展现 Top6**（8,932 / 4,270 / 1,892），说明三者在"能否获得展现"这一步没有明显差异，差异出现在展现之后的转化环节：

- A→B：展现量级相近或更高（B 展现是 A 的 2.1 倍），但阅读率相差 315 倍（6.3% vs 0.02%）——差异发生在 **Read Conversion 阶段**。
- A→C：阅读率同处于较高区间（6.3%、3.9%，均进入 46 篇阅读率 Top4），但收益一个有一个为零——差异发生在 **Monetization 阶段**。

当前样本显示，较高的上游表现并不必然伴随较高的下一阶段表现（例如酒店早餐券是"最高展现→极低阅读率"，亚马逊是"高阅读率→零收益"）。这是对现有 46 篇样本的观察事实，本轮未执行 Prediction Test（预测检验），不能推广为"某阶段的成功不能预测下一阶段"这类一般性结论。这三个案例本身不能推出规律，需要看下面的组级比较。

## L2-A｜Distribution Difference（展现差异）

**结果变量**：impressions
**分组**：展现 Top10（均值 2,617）vs 其余 36 篇（均值 561）

| 字段 | Top10 均值/中位数 | 其余36篇 均值/中位数 |
|---|---|---|
| word_count | 1,287.7 / 1,177 | 974.4 / 813 |
| 标题长度 | 26.8 / 28 | 22.6 / 23.5 |
| 发布小时 | 14.2 / 15.5 | 14.1 / 15 |

### 按星期归一化比较（Weekday Normalized Comparison）

直接比较"Top10中周三占比20% vs 其余36篇中周三占比42%"存在 Base-rate Problem（基率问题）：46 篇本身在周三发布的绝对数量就最多（17篇，占37%），占比对比会自动偏向"周三在Top10中占比更低"，不能据此判断周三表现差。改为按星期分别统计各自的展现、阅读率、收益篇数：

| 星期 | n | 展现 均值/中位数 | 阅读率 均值/中位数 | revenue>0 篇数 |
|---|---|---|---|---|
| 周一 | 6 | 1,008.7 / 752.5 | 0.30% / 0.00% | 1 |
| 周二 | 5 | 1,463.2 / 414.0 | 1.99% / 1.45% | 1 |
| 周三 | 17 | 1,056.4 / 466.0 | 0.73% / 0.30% | 2 |
| 周四 | 7 | 626.6 / 783.0 | 0.24% / 0.00% | 0 |
| 周五 | 6 | 970.5 / 1,030.0 | 0.35% / 0.27% | 0 |
| 周六 | 3 | 1,314.7 / 1,049.0 | 1.30% / 0.00% | 0 |
| 周日 | 2 | 439.0 / 439.0 | 0.33% / 0.33% | 0 |

**归一化后的观察**：周三（n=17，样本量最大、最可信）的展现均值（1,056）和阅读率均值（0.73%）均处于 7 天中的**中间水平**，不是最低也不是最高——并未显示出"周三表现不突出"。原先基于占比对比得出的"周三候选差异"在归一化后**不成立，应从 Candidate Difference 中移除，归入 No Evidence**。周二、周六阅读率均值较高（1.99%、1.30%），但 n 分别只有5和3，**Small-N，不构成可判断的差异**。

### Observed Difference
1. **字数**：Top10 展现文章字数均值（1,288）高于其余文章（974），中位数差异更明显（1,177 vs 813）。
2. **标题长度**：Top10 标题均值 26.8 字，长于其余文章的 22.6 字。
3. **发布星期**：归一化后无证据支持星期效应（见上表），移出候选。
4. **发布小时**：Top10 与其余文章的发布小时均值几乎相同（14.2 vs 14.1），**无可观察差异**。

## L2-B｜Read Conversion Difference（阅读转换差异）

**结果变量**：reading_rate = reads / impressions
**分组**：阅读率 > P75（0.96%）的 11 篇 vs 阅读率 ≤ P75 的 35 篇

| 字段 | 高阅读率组(n=11) 均值/中位数 | 低阅读率组(n=35) 均值/中位数 |
|---|---|---|
| word_count | 1,317.6 / 1,380 | 956.0 / 885 |
| 标题长度 | 22.8 / 25 | 23.7 / 24 |
| 发布小时 | 13.9 / 16 | 14.2 / 15 |
| read_duration（平台字段，秒） | 43.3 / 44 | 14.5 / 0 |
| read_complete_rate（平台字段，%） | 28.8 / 11.3 | 8.6 / 0 |

星期分布：

- 高阅读率组：周三×4, 周二×3, 周一×1, 周六×1, 周五×1, 周四×1（相对分散，周三占比 36%）
- 低阅读率组：周三×13（占37%）, 周四×6, 周一×5, 周五×5, 周六×2, 周二×2, 周日×2

### Observed Difference
1. **字数**：高阅读率组字数均值 1,318（中位数1,380），显著高于低阅读率组 956（中位数885）。这是本层唯一的**前置特征**差异（发生在阅读行为之前、文章本身自带的属性）。
2. **停留时长（read_duration）与完读率（read_complete_rate）**：高阅读率组均值分别为 43.3 秒 / 28.8%，明显高于低阅读率组的 14.5 秒 / 8.6%。**方法论标记（Outcome Leakage 提示）**：分组依据本身就是 `reading_rate = reads/impressions > P75`，而 read_duration、read_complete_rate 与 reading_rate 三者都是用户**已经点击进入阅读之后**才产生的行为记录，属于同一环节的不同侧面。因此这一发现只能定性为 **Confirmed Association（确认的伴随关系）**——它证明"阅读之后的行为指标"共同变化，读者一旦点击，读得也更久更完整；但它**不能**回答"什么前置特征导致了更高的阅读转换"，不应作为解释 Read Conversion 差异的核心证据。
3. **标题长度、发布小时**：两组之间差异幅度小，且标题长度方向出现反转（高阅读率组 22.8 字 < 低阅读率组 23.7 字），**未观察到稳定差异**。
4. **发布星期**：见下方 §L2-A 补充的按星期归一化比较，同一套结论适用于本层——样本量不足以在星期维度上区分高低阅读率组。

## 总结分类

### 1. Confirmed Association（确认的伴随关系，非前置解释）
- 高阅读率组的 read_duration（停留时长）和 read_complete_rate（完读率）显著高于低阅读率组（L2-B，43.3s vs 14.5s；28.8% vs 8.6%）。**方法论限定**：三者同属阅读发生后的行为指标，与分组变量 reading_rate 存在 Outcome Leakage，只能证明"阅读行为内部的指标共同变化"，不能作为解释"什么前置特征带来更高阅读转换"的 Confirmed Difference。
- 收益组（4篇）的 impressions、reads 均值远高于零收益组（42篇）（L2-C），但需注明该差异带有平台收益计算机制本身的结构性关联，不是独立解释变量，且 n=4，Small-N。

本轮 L2 在严格意义的"前置特征 → 结果"层面，**没有强度足以标记为 Confirmed Difference 的发现**——这本身也是一个真实结论，不是分析失败。

### 2. Candidate Difference（样本中出现、证据不足、需 L3 进一步检验）
- **字数（优先级最高）**：Top10展现文章、高阅读率文章、收益文章三组的字数均值均高于对照组（1,288 / 1,318 / 1,318.5 vs 974 / 956 / 1,016），是三个不同结果变量（展现、阅读转换、收益）方向一致的唯一前置特征。**禁止解读为"长文表现更好"**——存在 Confounder 风险：题材本身可能同时决定文章长度和表现（例如某类题材天然需要写得更长，也天然更容易获得展现/阅读/收益），字数可能只是题材的代理变量，而非独立起作用的因素。需要 L3 结合题材维度做进一步检验。
- **标题长度（降级为弱 Candidate）**：在 L2-A（展现）和 L2-C（收益）两阶段方向一致（高表现组标题更长：26.8 / 28.0 vs 22.6 / 23.1），但在 L2-B（阅读转换）阶段方向反转（高阅读率组 22.8 字 < 低阅读率组 23.7 字），三阶段证据不统一，优先级低于字数。

### 3. No Evidence（当前46条数据未显示出稳定差异）
- **发布星期**：原候选"周三表现不突出"在按星期归一化统计（各星期分别计算 n、展现均值/中位数、阅读率均值/中位数、收益篇数）后不成立——周三（n=17）的展现和阅读率均值均处于7天中间水平。周二、周六阅读率均值虽较高，但 n 仅5和3，Small-N，不构成可判断差异。移出候选。
- 发布小时：展现分组、阅读转换分组均显示高低组之间发布小时均值/中位数几乎一致（差异<1小时），无证据支持"发布时段"与展现或阅读转换存在可观察差异。
- 评论数（comments）：收益组与零收益组均值差异极小（0.25 vs 0.12），且全数据集评论总数仅6条，基数过小，无法判断。
