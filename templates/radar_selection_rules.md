# 爆点文案筛选层规则

## 位置

```text
老师网站爆点文案池
        ↓
爆点文案筛选卡 radar_selection
        ↓
今日入选文案
        ↓
Shared 参数
   ├─ A线直转
   └─ B线复刻
```

## 筛选对象

筛选对象不是原始热点，而是老师网站已经生成完成的爆点文案。

默认老师网站产出的文案已经合格，所以这里不判断“文案写得好不好”。

## 四个判断

### 1. 是否适合你的头条账号

看：

- 是否属于账号当前内容范围
- 是否适合普通大众阅读
- 是否过度垂直
- 是否需要专业背景
- 是否和账号历史高表现题型接近

### 2. 热点还有没有发布时间窗口

看：

- 事件是否仍在发酵
- 是否已经过时
- 是否今天仍有讨论价值
- 能否支撑两篇错峰发布
- 4-6 小时后发 B 稿是否还有效

### 3. 能不能拆成 A/B 两篇

看：

- 能否生成两个明显不同标题
- 能否用两套表达展开
- 是否有足够事实和冲突
- 两篇是否容易高度重复
- 是否适合中间插入其他题后再次发布

### 4. 值不值得占用当天发布名额

比较：

- 冲突强度
- 普通人相关度
- 利益或风险强度
- 评论空间
- 时效性
- 账号适配度
- 今日爆款评分

## 优先级

### P1｜当天必须优先发

满足：

- 账号适配高
- 普通人相关度高
- 冲突强
- 仍在时效窗口
- 适合 A/B 双线
- 今日爆款评分高

进入：

```text
A稿 -> 插入其他题 -> B稿
```

### P2｜可以发，但只发一篇

常见情况：

- 热点不错，但不适合双线
- 事实太少
- 两篇容易重复
- 热点窗口较短
- 今日爆款评分不错，但综合条件不足以占用双线

只走 A线。

### P3｜有空位再发

题目合格，但：

- 普通人相关度一般
- 评论空间弱
- 冲突不够集中
- 和当天其他题重复
- 今日爆款评分一般

### 不发

例如：

- 已过时
- 太垂直
- 与账号不符
- 事实风险高
- 需要大量补证
- 同类题当天已经过多

## 平台评分加权

使用一个轻量字段：

- 今日爆款评分：0-100

处理原则：

- 同等条件下，优先选择今日爆款评分高的文案。
- 评分高不能覆盖账号不适配、事实风险高、热点过时等硬伤。
- 今日爆款评分高，且账号适配、普通人相关度、冲突强度为高时，优先进入 P1。
- 今日爆款评分高但双线适配为 NO 时，优先考虑 P2，只走 A线。
