# 爆点文案筛选卡

筛选对象是老师网站已经生成完成的爆点文案，不是原始热点。
筛选前必须先把文案雷达完整原文保存到 `data/radar_pool/`。

## 最小筛选参数

| 参数 | 取值 | 备注 |
| --- | --- | --- |
| 头条账号适配 | 高 / 中 / 低 | 是否属于账号当前内容范围，是否接近历史高表现题型 |
| 普通人相关度 | 高 / 中 / 低 | 是否适合普通大众阅读，是否过度垂直 |
| 冲突强度 | 高 / 中 / 低 | 冲突是否集中、清楚、有讨论性 |
| 利益或风险强度 | 高 / 中 / 低 | 是否有明确利益、损失、风险或成本 |
| 评论空间 | 高 / 中 / 低 | 是否容易引发评论和站队 |
| 热点剩余时效 | 长 / 中 / 短 | 是否仍在发酵，是否能支撑 4-6 小时后的 B 稿 |
| 今日爆款评分 | 0-100 | 老师网站/平台给出的今日爆款、确认S+、素材质量等分数 |
| 双线生产适配 | YES / NO | 是否能生成 A/B 两篇明显不同文案 |
