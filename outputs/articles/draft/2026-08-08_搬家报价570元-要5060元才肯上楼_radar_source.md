# 2026-08-08 搬家报价570元 要5060元才肯上楼

标题3：线上报价570元，搬家师傅坐地起价到5060元

## 正文

线上报价570元，实际却付了5060元，家具才被搬上楼——这单价格差了近9倍的搬家账单。

市民陈女士通过线上平台联系了一家搬家公司，对方给出的报价是570元。搬家当天，师傅按家具单独计费。师傅解释，还有楼层费、大件上楼费、工时费。最终，陈女士支付了5060元，家具才被搬上楼。

陈女士通过线上平台得到的报价是570元，平台回应称，570元只是起步价。师傅则解释，还有楼层费、大件上楼费和工时费。

平台和师傅各自的说法是否成立，本身还有讨论空间；但从已确认的信息来看，最直接的事实是：线上报价570元，最终支付5060元，两者之间存在巨大的价格差。

律师提醒，如果搬家公司以控制货物的方式强迫消费者接受加价，可能涉嫌强迫交易罪，建议消费者遇到类似情况录音录像，并及时报警。

搬家对大多数人来说是低频消费。对准备搬家的人来说，更实际的做法是下单前把费用明细问清楚，比如是否还有楼层费、大件上楼费、工时费。

## Fact Boundary Review 记录

### 第一轮：REVISION（3处）

1. "工时费一项项往上加"——"一项项往上加"描述了未经确认的具体计价过程，Source 只能确认"师傅按家具单独计费，并解释有楼层费、大件上楼费、工时费"，不能确认计价的具体先后顺序或方式。改为"师傅按家具单独计费，并解释还涉及楼层费、大件上楼费、工时费"。
2. "楼层费……本来就该另算"——"本来就该另算"是对师傅立场的增强表达，Source 只能确认"师傅解释有楼层费、大件上楼费、工时费"，不能确认师傅主张这些费用"本来就该"另算。改为"师傅则解释，还有楼层费、大件上楼费和工时费"。
3. "很难提前摸清一家公司完整的收费结构"——"低频消费"可以作为一般性分析保留，但"因此很难提前摸清完整收费结构"是未经证实的普遍因果判断。收回到 Source 已有的提醒内容，改为"搬家对大多数人来说是低频消费。对准备搬家的人来说，更实际的做法是下单前把费用明细问清楚，比如是否还有楼层费、大件上楼费、工时费。"

其余内容 PASS，包括"平台和师傅各自的说法是否成立，本身还有讨论空间"——这是明确标识的分析判断，未伪装成本案事实。

### 第二轮：REVISION（4处，第一轮 PASS 判断被推翻重审）

第一轮审核未按 Fact Boundary Review Prompt 的机械标准逐句执行，"听起来合理"和"Source 能确认"被当成了同一证据等级，导致以下4处被误判为 PASS：

1. "并解释还涉及……"把"师傅按家具单独计费"和"师傅解释有楼层费等"这两件独立事实绑定到了同一时点，Source 没有明确"解释"发生在"到场计费"的那个时点。拆开为两句："师傅按家具单独计费。师傅解释，还有楼层费、大件上楼费、工时费。"
2. "陈女士下单时看到的报价是570元"——Source 只写"通过线上平台找搬家公司，报价570元"，没有记录"下单时看到"这个具体交互状态，属于未经确认的过程细节。改为"陈女士通过线上平台得到的报价是570元"。
3. "平台事后回应称"——"事后"是新增的时间关系，Source 只写"平台回应称570元是起步价"，没有提供回应发生的具体时间。删除"事后"，改为"平台回应称，570元只是起步价"。
4. "对陈女士来说，最直接的事实是"——"对……来说什么最直接"是替人物定义认知重点，属于未经确认的主观视角，Fact Boundary 明确禁止。改为"从已确认的信息来看，最直接的事实是"，完全退出人物心理，同时把"下单时看到的数字/最终支付的数字"改回"线上报价570元/最终支付5060元"，避免重复使用第2处已收紧的"下单时看到"表述。

本轮教训：Fact Boundary Review 必须机械执行"Source 能不能支持"这一个标准，不能因为一句话在现实中大概率如此、读起来顺理成章，就放宽到"合理推断"的证据等级。"下单时看到570"和"线上报价570"现实中几乎等价，但证据等级不同，前者是过程细节的补全，后者才是 Source 原句能直接支持的表述。

## Source Format / Target Format 判断

- Source Format：短视频文案创作包（45秒终审版，五段结构，目标150-220汉字，口播节奏）
- Target Format：今日头条图文文章
- 判断结果：跨格式转换——不继承源格式的时长/字数区间/口播节奏，只继承 Narrative Spine（Hook → Fact → Conflict → Ordinary-person Stakes → Comment），Fact/Conflict/Stakes 各展开为2段，正文共7段。
